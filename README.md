
# Student Performance Analysis

## 1. Project Overview
This project analyses student academic performance using Python. It explores the relationship between study hours, subject marks, attendance and overall student performance.

## 2. Objectives
- Create and analyse a student performance dataset.
- Calculate average, median, maximum and minimum marks.
- Compare performance across different subjects.
- Categorise students based on their average marks.
- Visualise the data using four different charts.

## 3. Dataset Description
The dataset contains 20 student records.

The dataset includes:
- Student ID
- Study Hours
- Mathematics Marks
- Physics Marks
- Chemistry Marks
- Attendance Percentage
- Average Marks
- Performance Category

## 4. Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- NumPy
- GitHub

## 5. Data Analysis
The following computations were performed:
- Mean and median

- Subject-wise average
